WORKING TOOLS
--------------------------------------------------------------------------------

1. ping_monitor.py (8.2KB, 260 lines)
   Features:
   - Real-time latency monitoring to multiple servers
   - Statistics tracking (average, min, max, standard deviation)
   - Packet loss detection
   - Jitter measurement
   - Automatic best server selection
   - Cross-platform support (Windows, Linux, macOS)
   
   Usage:
   $ python3 ping_monitor.py
   
   Output:
   - Color-coded latency indicators
   - Real-time statistics table
   - Historical tracking (last 60 samples)
   - Best server recommendation

2. route_analyzer.py (8.8KB, 269 lines)
   Features:
   - Network route tracing (traceroute wrapper)
   - Bottleneck identification
   - Hop-by-hop latency analysis
   - Multi-server comparison
   - Optimization recommendations
   - Cross-platform traceroute handling
   
   Usage:
   $ python3 route_analyzer.py
   
   Output:
   - Complete route path visualization
   - High-latency hop identification
   - Specific optimization suggestions
   - Comparison summary for multiple targets
